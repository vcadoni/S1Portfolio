# S1Portfolio
All my python projects from Semester 1 of APCSP 

MultiplicationQuiz:
The Multiplication Quiz file was a project made to help people practice their multiplication skills in small quizzes of 5 questions. The program generates 2 numbers between 1 and 12, and once the user answers the question, it tells them if they were right or wrong and how many out of the 5 questions they've gotten right so far. At the end of the quiz, it gives the user a percentage of how many they got right.
Key features: Quizzes in sets of 5, simple multiplication using numbers 1-12

whileLoops:
The whileLoops project was one that just introduced me to while loops and how to use them. In this program I made a simple calculator that took two integers and did one of the 4 operations to give the user an answer. The while loop came to play when it asked the use if they want to give it another math problem and they could choose to quit or keep going. In this program I also used global functions to make sure my functions for the operations were usable in the main calculator function.

RockPaperScissors:
The rock, paper, scissors game was where the user picks one of them to play against the imaginary robot 'bobby' that randomly generates his own play, and the user sees if they won or not and can keep track of wins, losses, and ties. 
Key feautures: display of their score after each round, can play as many times as they want

pokemonProject:
The pokemon project was a long one, where we made a game using a pokemon character and the user trained it. I chose the character Eevee and used two of her evolutions, vaporean and flareon, to show the player's progression. Training the pokemon would make it go up a level, challenging someone to a gym battle would result in either going up 2 levels or nothing happens, and letting the pokemon take a nap would show the user a display of their level and avatar. Once the player got to level 5, eevee would evolve to Vaporean, and once it reached level 20 it would become flareon. This is also the project that introduced me to global functions because I needed them in the displays of the characters, the level, the names, and the day of playing. 
Key Features: Gym battles can upgrade the level up 2 if it wins, the character evolves after certain levels, the display feature shows all of the pokemon's stats.

MadLibs:
The Madlib file was a game where the user gave input for things like a name, place, animal, etc to make a silly sounding story.
Key features: Variables, input functions, string concatenation
